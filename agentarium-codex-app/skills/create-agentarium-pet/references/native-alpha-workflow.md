# Native transparent generation

This workflow replaces the historical chroma-key workflow for new Agentarium art.

1. Obtain the recipe and read `animation-rows.md`. Generate a canonical original full-body character on a genuinely transparent RGBA background using the host image generation tool. Request no checkerboard, colored key, ground shadow, scene, captions or grid. Inspect the alpha channel; a painted checkerboard or opaque image fails. Regenerate at the image tool if necessary. Do not use background removal, color-keying, edge despill or RGB painting to fabricate transparency.
2. Generate real animation poses from that approved reference. Use the exact counts and semantics in `animation-rows.md`. Individual frames or well-separated strips are acceptable. Each pose must have transparent margins and consistent identity, view, scale, baseline and palette. Keep actual source files and prompts. Cropping strips at transparent cell boundaries is allowed; reject clipped or overlapping poses. Do not duplicate or geometrically transform stills to fake an animation.
3. Save a manifest with `rows` as eleven arrays of source frame paths (relative to the manifest), plus `neutral` as a separate neutral-frame path. Counts: `[6,8,8,4,5,8,6,6,6,8,8]`. For each direction use the specified gaze, not a rotated sprite. Run `scripts/assemble_native_alpha.py manifest.json output/spritesheet.webp`. It preserves generated alpha, fits complete frames into 192×208 cells, and keeps unused cells transparent. It does not extract a background. Provide consistently framed sources; the assembler uses one shared scale for all frames.
4. Inspect every row as a temporal sequence for smooth motion, identity, clipping, baseline/scale jumps, closed loops, correct direction and expression. Inspect transparent edges on light and dark backgrounds. Verify cardinal gaze directions without labels before judging intermediate directions. Repair the generated sources when they fail. Save the manifest, prompts, alpha report and visual QA decisions.
5. Package `pet.json` with id, displayName, spriteVersionNumber 2 and spritesheetPath `spritesheet.webp`; include `palette.json` with sourceHue, hueTolerance, minSaturation 0.12 and minValue 0.45. Deliver the canonical atlas. Agentarium swaps its color family in the display shader. Never bake palette colors into the canonical atlas. Optional precolored ZIP export is for other consumers.

For Agentarium status items, generate bomb, flask, question mark, washbasin, balloon, gift and zzz as separate transparent images. Render them as independent un-tinted overlays at the character's upper right. A separate sleeping pose may be supplied for completed/resting display; it must be generated with the same identity and native alpha, not synthesized by modifying eyes in code.

Report generation and verification honestly. If native transparent output is unavailable, keep the recipe and report the limitation instead of silently reverting to chroma-key generation.
