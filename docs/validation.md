# Windowsプレビューの検証記録

実施日：2026-09-06。Windows x64 / NVIDIA RTX 5060 / Godot 4.7 Compatibility / Gua 1.0.10。

## 合格した検証

- **状態管理29項目**：重複、順序逆転、質問と確認の分離、明示的再開、不正入力、URL、保存復元、破損スナップショットの拒否。
- **Codex JSONLアダプター6観点**：イベント変換、プライベート本文をコピーしない、イベントID、途中切断、失敗、壊れたJSON。公式形式のフィクスチャを使用。実API実行はしていない。
- **Gua UIスイート19操作**：6状態の表示、確認後の状態保持、集中モード、動き低減、マスコット切り替え、ペット巡回、実作業/デモ切り替え。開発起動とRelease EXEの両方で合格。
- **Guaのポインター入力**：マスコットを (1100,550) → (1130,570) にドラッグ。Window.positionの実測が入力差分 (30,20) と一致。
- **実ファイル受信**：外部JSONでDEMOからLOCALへ遷移。題名・要約・質問待ちがGuaツリーに現れる。
- **再起動**：開発版で保存した未確認の質問がRelease EXE起動後にも残る。
- **実ローカルプロセス**：副作用のない終了コード0/7のプロセスを起動。完了/失敗へ遷移し、Guaで要約を確認。
- **Codexフィクスチャの接続**：JSONL → inbox → アプリ → Guaの完了表示まで確認。
- **Release書き出し・起動**：EXEとGua Release DLLで起動。公式アーカイブのSHA-256を照合。

UI操作・画像取得はすべてGua経由。付属の `tests/gua-driver.ts` はGua公式 `GuaBridgeClient` を使用する。8765番が前のプレビューHTTPサーバーと競合したため、18765番を使用した。別の画面操作ツールは使用していない。

`artifacts/gua-ui-results.json` に19件の相関付き成功レシート、`artifacts/screenshots/` に各状態のGuaスクリーンショットを保存。

## ウィンドウの観測

マスコット時のGodot Window実値：360×320、transparent=true、transparent_bg=true、borderless=true、unfocusable=true、透過ポリゴン12点、トレイあり。Guaが取得したPNGは透明背景を持つ。

Guaはアプリ内入力を注入するため、**背後の別アプリがクリックを受け取ること、実マウスでの全挙動、OSトレイのメニュー操作そのものは未検証**。透明部分の全ピクセルを判定する方式ではなく、カード・キャラ・ボタンを囲む多角形による透過である。トレイの生成と機能分岐は実装済み。

## 待機時の参考測定

Gua無効、Release EXE、360×320マスコット、idle状態。起動3秒後から10.01秒間の単発測定。

| 項目 | 結果 |
| --- | --- |
| CPU時間 | 0.0938秒 / 10.01秒 |
| CPU使用率換算 | 1コア基準 約0.94%、16論理CPU全体基準 約0.059% |
| ワーキングセット | 239.85 MiB |
| Private Bytes | 200.49 MiB |
| プロセスのInputIdle到達 | 467 ms |
| EXE | 109,241,344 bytes |

InputIdleは「最初の描画まで」の時間ではない。GPU負荷・長時間常駐・多画面・低スペックPC・作業中の負荷は未測定。メモリは小さくないので、軽量性の宣伝には使わない。生値は `artifacts/benchmark.json`。

ビルドを制限環境で行うとGodotのOS証明書ストア読み取りエラーが出るが、ネットワークを使わない本アプリのパース・export・起動は成功。制限外のUIテスト起動ではこのエラーは出なかった。

## 対象外

Codexデスクトップの自動同期、GitHub API接続、Store提出、署名、他OS、背景統合、フルスクリーン検知、外部Pet Pack、複数起動排他はこのプレビューに含まない。既知制約はREADMEにも記載。
