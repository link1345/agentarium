# Agentarium 0.2 検証記録

以下は0.2当時の検証記録です。現行仕様は [README](../README.md) を参照してください。

2026-09-06 / Windows x64 / Godot 4.7 / Gua 1.0.10。

## 自動同期

- 実際のCodexデスクトップから「AgentariumをGuaで開発」という名前と`inProgress`を取得し、Guaで画面内の同名・作業中表示を確認。
- ローカルのテストDBから、2スレッドの同時実行を分割表示。DBの完了更新へ自動追従することをGuaで確認。
- Guaで確認済みにした後、DB側を改名。新しい名前へ追従し、確認済みを維持した。
- Pythonテスト4件：正確な名前、内部サブエージェント／アーカイブ除外、状態遷移、改名、不明状態、DB不在時の非作成、読み取り専用、読み取り前後のDBハッシュ一致。
- 実DBには書き込んでいない。

証拠：`artifacts/screenshots/v02-wide-initial.png`、`v02-compact-initial.png`、`sync-transition.png`。初期スクリーンショットのキャラクターは画像組み込み前のもの。

## UI

- Gua公式`GuaBridgeClient`で24操作の回帰試験：6状態、集中モード、動き軽減、1600px幅分割、スレッド名、パレット操作、マスコット切替。
- ペット取り込みもGuaの`set_value`／`click`で操作。不正ZIPを拒否してアプリが動作し続けることを確認。
- UI操作・スクリーンショットはGua経由。ブラウザー操作ツールやスクリーン座標操作の別基盤は使用していない。
- 従来のイベントストア29チェックも通過。

## ChatGPT用アプリ

- `bun run test`：レシピの行順、パレット処理の色変更・アルファ／白／暗部保持、寸法違い拒否。
- 実HTTP `/mcp`：初期化、ツール一覧、生成レシピ呼び出し、スキル一覧と全リソースのSHA-256照合、不正ダウンロードURL拒否。
- 公式プラグイン検証スクリプトでマニフェストとスキルの検証に成功。
- ChatGPTアカウントへの登録、HTTPS公開、ChatGPT内での実行は未検証。ローカルMCPの検証と区別する。
