# GitHub自動同期（0.4.0）

GitとGitHub CLI (`gh`)をインストールし、`gh auth login --hostname github.com`でログインしてからAgentariumを起動する。
既存のCLI認証を使い、認証情報をAgentariumに保存しない。読み取りのみで、コメント投稿・レビュー送信・CI再実行はしない。

登録されたCodexタスクの作業ディレクトリからoriginリモートを読み、GitHub.comのリポジトリを特定する。
Codexに記録されたブランチがあればそれを使い、なければ現在のチェックアウトを使う。
originとupstreamにある開いたPRを調べ、ブランチ名とhead側リポジトリが一致するものだけを採用する。複数該当時は推測せず状態欄に表示する。
記録されたブランチが古い場合は、そのタスクで期待するブランチと一致しているか確認すること。

- PRあり: PRの最新headのCheck Runs/Commit Status失敗は爆弾、提出済みレビュー（承認・変更要求・コメント）は風船。
- PRなし: 対象ブランチ・コミットのGitHub Actionsを取得し、ワークフロー名ごとの最新実行が失敗なら爆弾。
- CI失敗とレビューが同時にあればCI失敗を優先。キャンセル・スキップ・実行待ちは失敗にしない。
- 同じイベントの取得では確認済み状態を戻さない。
- CI成功時はレビューがあればレビュー表示、それ以外はCodex状態へ戻る。
- 初めて接続したPRの既存レビューも表示対象。「確認した」で未確認マークを消せる。

約60秒間隔で取得する（通信時間や待ち行列により延びる）。Codex同期は別途2秒間隔で動作する。
GitHub情報はカード下部に表示し、取得先がある場合は「GitHub ↗」で開ける。
未認証・権限不足・通信エラーは状態欄に表示する。取得失敗時はGitHubの表示上書きを解除し、Codex状態を表示する。
GitHub Enterprise、GitLab、PRの一般コメント、レビュー依頼のみの通知は対象外。
