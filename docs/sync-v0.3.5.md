# 0.3.5 新規タスクの自動追加

名前未確定のタスクを同期対象から除外していた処理を修正。
会話の最初のプロンプトを名前として使わず、「新しいタスク · ID」で表示し、Codexの名前確定後に更新する。

起動中に初めて検出したタスクは一覧の先頭へ追加し、実接続表示中はそのタスクを選択する。
既存の並び順と非表示設定を維持する。起動直後の既存タスク取得は新着扱いしない。
