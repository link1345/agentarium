# Agentarium 0.3 検証記録

2026-09-06 / Windows x64 / Godot 4.7 / Gua 1.0.10。

- Guaで一覧の開閉、↑↓による並べ替え、×による非表示、＋による復元と手動追加を確認。
- 再起動後も非表示状態と先頭へ移動した順番を保持。復元後の先頭項目の↑が無効であることをGuaで確認。
- イベント受信による新規タスクの自動追加を確認。非表示タスクへの更新は非表示を維持する。
- 質問アラートのクリック解除と約4.5秒後の自動解除を確認。その後も質問カードの警告を維持。
- 状態アイテム7種と専用寝姿を組み込み。透過背景は画像生成時のアルファを保持し、背景除去は実施していない。
- 生成画像8点のアルファ確認を `artifacts/v03-alpha-validation.json` に記録。全画像で10%以上の透明画素を確認。
- 新しい透過アトラス組み立て処理のテスト2件、イベントストア29チェック、自動同期テスト4件を実行。
- 生成レシピの単体テスト3件とMCP経由の内蔵スキル照合を実施。新しいレシピ項目に対応する出力スキーマを更新。
- UI操作とアプリ画面撮影はGuaのみ。テストイベントの投入はテスト用inboxへ行い、実CodexのDBには書き込んでいない。

質問・CI失敗・レビューは明示イベントで検証した。現行のCodex DBのinProgressから質問待ちを区別することはできず、自動検出したという主張はしない。ChatGPTアカウントへの接続登録・公開はこの版でも未実施。

Guaスクリプト: `tests/gua-driver.ts v03`。証拠: `artifacts/gua-v03-results.json` と `artifacts/screenshots/v03-*.png`。

最終Windows Release EXEで30操作のGuaシナリオが通過。実Codexのスレッド名の同期を再確認した。最終取得時のDB状態はinterruptedで、画面の「おやすみ」と一致した。実際のデスクトップで進行中に見えていてもローカル投影が遅れる可能性は残る。アラート文字サイズの最終調整後も配布版で表示と自動解除を確認。MCPスモークは出力スキーマ修正後に合格。


## 0.3.1
Guaのポインター移動・押下・移動・解放でドラッグ＆ドロップを検証。移動先の線、並び順変更、通常時の追加・削除ボタン非表示、編集モードの表示、非表示と復元、編集終了を確認。ドラッグ中は同期によるUI再構築を遅延し、ドロップ後に適用する。

0.3.1 Windows配布版でGuaのドラッグ＆ドロップ・編集表示・非表示／復元が合格。再起動後もドラッグした順番を維持し、通常モードでは＋・×が表示されないことを確認した。証拠はartifacts/gua-v031-results.jsonとv031-*.png。

## 0.3.2
ドラッグは編集モード中のみ有効。Guaで通常時の順序保持と編集時の移動を確認。追加はCodexディープリンクに変更し、URL書式検証、重複防止、非表示項目の復元に対応。同期テスト5件が合格し、直近24件より古いリンク対象の取得も検証した。

0.3.2 配布版で、追加したリンクのスレッド名「AgentariumをGuaで開発」がローカルCodexから取得されることをGuaで確認。同期対象として保存され再起動後も保持される。データがないリンクは未接続と表示し、任意URLを開く処理は行わない。

## 0.3.3
Guaで上下移動ボタン・状態の小文字・タブの撤去を確認。編集前後の一覧幅248pxを比較し、×が名前欄の右で同じ行にあることを検証。全7種類のスタンプがキャラの状態アイコンと一致し、狭い画面で一覧から対象を選べることを確認。編集時のドラッグと非表示／復元も回帰確認した。証拠はartifacts/gua-v033-results.json、screenshots/v033-*.png。
