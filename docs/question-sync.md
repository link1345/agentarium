# 0.4.2 質問待ちの同期

Codex履歴のrequest_user_input / request_user_input_asyncの呼び出しを検出し、質問待ち・はてな・全画面アラートを表示する。
質問本文や回答本文は保持せず、呼び出しIDと待機状態のみを保持する。
非同期ツールの受付完了は回答ではないため、質問状態を解除しない。ターン終了後も維持する。
同期ツールの返却、次のユーザー入力、次のターン開始、中断・失敗によって解除する。
通常の文章に含まれる質問、ツール使用の承認待ち、exec内で間接的に呼び出され履歴に独立した関数呼び出しが残らない質問は対象外。
質問待ちはGitHubのCI失敗・レビュー表示より優先する。
